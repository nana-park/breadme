# Home 기본 구조

## 목적과 현재 상태

HR 담당자가 데스크톱과 모바일에서 같은 순서로 내용을 읽고 다음 행동을 찾을 수 있는 **구조 검토용 화면**입니다. Home 콘텐츠 이관이나 최종 디자인 완료를 의미하지 않습니다.

현재 라우트는 `/` 하나입니다. `#overview`, `#projects`, `#contact`는 실제 페이지 내부 영역으로 이동하며 새로고침·뒤로 가기에도 동작합니다. 여러 페이지 개발을 시작할 때 라우터와 호스팅의 경로 처리를 함께 결정합니다.

## 화면 순서

1. Header: 원본 breadme 로고, 소개·프로젝트·연락 안내 메뉴
2. Overview: 이름, 기존 원문의 영어 소개, 두 개의 실제 링크, 구조 미리보기 안내
3. Projects: 문제·역할·성과를 설명할 자리 표시. 실제 사례나 성과가 아님
4. Contact: 기존 공개 포트폴리오로 이동. 문의 전송 기능은 없음
5. Footer: 미리보기 상태, 맨 위로 링크

## 내용을 바꾸는 곳

- 소개와 자리 표시 문구: [`../../content/site/homeContent.ts`](../../content/site/homeContent.ts)
- 검증된 기존 사이트 링크: [`../../content/site/siteMetadata.ts`](../../content/site/siteMetadata.ts)
- 메뉴·버튼 공통 문구: [`../../locales/ko/common.ts`](../../locales/ko/common.ts)
- 공통 공식 명칭: [`../../content/shared/terms.ts`](../../content/shared/terms.ts)
- 메뉴 대상: [`../../config/navigation.ts`](../../config/navigation.ts)

영어 Hero는 [기존 HTML](https://github.com/nana-park/Portfolio/blob/main/index.html)의 원문입니다. 새 한국어 번역이나 경력·성과를 만들지 않았습니다. 영어 UI는 아직 준비되지 않아 언어 선택 버튼도 없습니다.

## 사용 중인 공통 컴포넌트

Header, Footer, Container, SectionTitle, ActionLink. 다른 페이지는 아직 없으므로 적용 완료로 표시하지 않습니다. 이동은 실제 `<a>` 링크, 메뉴 열고 닫기는 `<button>`으로 구분합니다.

## 반응형과 접근성

- 데스크톱: Hero 2열, 설명 카드 3열, 항상 보이는 내비게이션
- 태블릿: 여백 축소, 제목·연락 영역 세로 배치
- 모바일: 같은 DOM 순서의 1열, 줄바꿈 가능한 제목, 전체 폭 주요 링크, 펼침 메뉴
- 숨겨지는 것은 접힌 메뉴뿐입니다. 콘텐츠와 주요 다음 행동은 제거하지 않습니다.
- 메뉴는 본문 흐름 안에서 펼쳐집니다. 모달이 아니므로 화면 잠금·포커스 가둠을 적용하지 않습니다.
- Escape 닫기, 토글로 닫기, 링크 선택 후 닫기와 대상 포커스, 화면 크기 변경 시 메뉴 상태 초기화
- 본문 바로가기, 시맨틱 제목, 포커스 표시, 44px 이상 조작 높이, 감소된 모션 선호 반영

## 디자인 예외

승인된 예외 없음. 현재 중립 색상·타이포 토큰은 구조 확인용 초안이며 최종 디자인 승인 상태가 아닙니다.

## 검수할 상태

- 320 / 390 / 767 / 768 / 1024 / 1025 / 1440px
- 키보드, Escape, 반복 열기·닫기, 메뉴 선택, 경계 폭 전환
- 앵커 직접 진입, 새로고침, 뒤로·앞으로 이동
- 200% 글자 확대, 가로 넘침, 터치 영역, reduced motion
- 콘솔 오류와 자동 접근성 검사

실행 결과와 한계는 [검수 기록](../../../docs/qa/foundation-verification.md)에 별도로 기록합니다.
