# Ground Rules

이 폴더는 `Portfolio-React`의 장기 협업 규칙을 보관합니다.

| 파일 | 역할 |
| --- | --- |
| `01-repository-and-branching.md` | 저장소, 브랜치, PR과 병합 권한 |
| `02-directory-structure.md` | 페이지 중심 폴더, README와 공통화 점검 |
| `03-naming-conventions.md` | 폴더, 파일, 컴포넌트와 에셋 이름 |
| `04-backup-and-release.md` | 백업, 복구와 민감 정보 |
| `05-development-workflow.md` | 개발 순서와 제한된 테스트 |
| `06-code-organization-and-comments.md` | WHAT·WHY 주석, 코드 위계와 디자인 예외 |
| `07-review-and-notifications.md` | 사용자 확인 상태와 알림 |
| `08-css-and-responsive-styles.md` | CSS Modules, 스타일 소유권과 반응형 규칙 |
| `09-design-system-governance.md` | 디자인 시스템 범위, 예외 승인과 기록 |
| `10-content-and-localization.md` | 콘텐츠 원본, 공통 명칭과 한국어·영어 관리 |

버전 번호와 변경 이력은 찾기 쉽도록 최상단 [`versions/`](../../versions/README.md)에서 관리합니다.

## 문서 관리

- 읽는 순서가 있는 규칙 문서는 두 자리 숫자 접두사를 사용합니다.
- 파일명은 영문 소문자 `kebab-case`를 사용합니다.
- 하나의 문서는 하나의 주제를 다룹니다.
- 규칙이 바뀌면 인덱스와 관련 템플릿도 함께 확인합니다.

## 우선순위

1. 사용자 데이터와 기존 운영 사이트 보호
2. `main` 안정성과 사용자 승인
3. 화면과 기능의 회귀 방지
4. 기획자와 개발자가 이해할 수 있는 구조
5. 재사용성과 일관성
6. 개발 편의성
