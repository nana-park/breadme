# 백업과 복구

## 원칙

- 기존 HTML은 `nana-park/Portfolio`에 보존합니다.
- React에서 이전 파일을 `backup/`, `old/`, `final/` 폴더에 복사하지 않습니다.
- 커밋, 브랜치와 태그로 이전 상태를 보존합니다.
- `.env`, API 키, 토큰과 개인 인증 정보는 커밋하지 않습니다.

## 기준점

기존 HTML 저장소에는 다음 기준점을 권장합니다.

```text
branch: legacy-html
tag: html-v1-final
```

React의 버전 번호, 변경 이력과 릴리스 상세는 [`versions/`](../../versions/README.md)에서 관리합니다.

## 복구

1. 문제 범위를 확인합니다.
2. 마지막 정상 태그를 확인합니다.
3. 복구용 `fix/*` 브랜치를 만듭니다.
4. 정상 버전을 다시 배포합니다.
5. 원인을 별도 수정합니다.
6. `beta` 검수 후 `main`에 반영합니다.

현장에서 여러 파일을 임시 수정하거나 백업 복사본으로 덮지 않습니다.
