# 사용자 확인과 알림

## 확인 상태

- `필수 승인`: 승인 전 `main` 병합 불가
- `확인 권장`: 개발자 권장안으로 진행 가능
- `참고`: 별도 결정 불필요
- `수정 중`: 수정본이 나오기 전 알림 중단

승인은 명시적인 답변만 인정합니다. 단순한 “확인”은 모호하면 다시 확인합니다.

## 기록

- PR: 항목별 체크리스트와 최초 대기 시각
- `versions/releases/vX.Y.Z.md`: 버전별 승인 상태
- `versions/README.md`: 현재 대기 건수와 main 반영 가능 여부

## 디자인 예외 승인

디자인 시스템 예외는 항상 `필수 승인`입니다. 구현 전에 채팅에 `⚠️ 디자인 예외 승인 필요` 경고와 기본 규칙, 제안 예외, 이유, 영향 범위, 대안과 재검토 조건을 표시합니다.

사용자 승인 전에는 구현하거나 승인된 예외 목록에 기록하지 않습니다. 승인 후에는 코드, 페이지 README, 중앙 예외 목록, PR과 관련 릴리스 기록을 함께 갱신합니다.

상세 절차는 [`09-design-system-governance.md`](09-design-system-governance.md)를 따릅니다.

## 모바일 알림

작업 완료 자체는 알리지 않습니다. 미확인 항목이 있을 때만 GitHub 멘션으로 알립니다.

```text
대기 시작 후 12시간: 1차 알림
대기 시작 후 총 36시간: 2차 알림
```

알림 시간대 제한은 없습니다.

수정 요청을 받으면 타이머를 중지하고, 수정본이 새로 준비된 시점부터 다시 계산합니다. 일부 승인 시 남은 항목만 알립니다.

## 36시간 이후

모바일 알림을 반복하지 않습니다. 이후 Portfolio-React 관련 Codex 작업을 시작할 때 답변 첫 줄에 다음처럼 짧게 표시한 후 질문에 정상적으로 답합니다.

```text
확인 대기 2건 — [Home·Mobile] Hero 줄바꿈, [Navigation] 메뉴 순서
```

대기항목은 작업을 막지 않지만, `필수 승인`이 남아 있으면 `main` 병합은 막습니다.
