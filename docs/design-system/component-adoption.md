# 공통 컴포넌트 적용표

기본 구조에서 실제 연결한 컴포넌트만 기록합니다. Home은 구조 미리보기이며 콘텐츠·최종 디자인 완료를 의미하지 않습니다.

상태: `적용`, `적용 대기`, `디자인 예외`, `해당 없음`. 아직 페이지 자체가 없으면 `미구현`으로 표시합니다.

| Footer | 적용 | 미구현 | 미구현 | 미구현 | 미구현 | 미구현 | 미구현 | 미구현 |
| Container | 적용 | 미구현 | 미구현 | 미구현 | 미구현 | 미구현 | 미구현 | 미구현 |

## 범위

- Home 안의 Projects·Contact 섹션은 개별 Projects·Contact 페이지가 아닙니다.
- ActionLink는 이동 목적의 `<a>`입니다. 메뉴 조작은 Header 내부의 기본 `<button>`을 사용합니다. 공통 Button은 아직 만들지 않았습니다.
- 공통 컴포넌트 내부 스타일은 해당 CSS Module이 관리합니다.
- 이번에는 다른 완성 페이지가 없으므로 페이지 간 전체 공통화 검토는 해당 없습니다.
- 디자인 예외 없음. 현재 토큰은 기존 white/black/orange 계열을 따른 구조 검토용 값이며 최종 승인 아님.

## 갱신 기준

공통 컴포넌트 승격·API 변경 시 영향받는 모든 페이지의 상태와 README를 함께 갱신합니다. `적용 대기`는 실제 구현 페이지의 미이관 항목에만 사용합니다. 디자인 예외는 별도 승인과 기록이 필요합니다.
