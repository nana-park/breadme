## 자동 브라우저 검사의 범위

`tests/e2e/foundation.spec.ts`는 10개 검사를 정의합니다.

- 320 / 390 / 767 / 768 / 1024 / 1025 / 1440 CSS px의 7개 크기
- 단일 h1, 이관 대기 표시, 페이지 가로 넘침, 모바일 1열·넓은 화면 카드 3열
- 실제 앵커 목적지, 이동한 영역 포커스, 새로고침
- 주요 링크·버튼의 최소 44×44px 크기
- axe WCAG A/AA 자동 접근성 검사와 콘솔 오류
- 모바일 메뉴 반복 열기·닫기, Escape·포커스 복귀, 뒤로·앞으로 이동
- 767↔768px 전환 시 숨겨지는 메뉴 버튼/링크에서 보이는 컨트롤로 초점 이동
- 본문 바로가기, reduced motion, `html` 글꼴 크기 200% 확대

200% 검사는 **루트 글꼴 확대**입니다. 실제 브라우저 UI의 페이지 줌, 모든 화면 읽기 프로그램, 실기기 터치 테스트를 대신하지 않습니다.

## 검수 중 수정한 사항

- Header의 원본 breadme 로고와 white/black/orange 계열 보존
- 화면 크기 변경·뒤로 이동 때 숨겨진 메뉴에 키보드 초점이 남지 않도록 처리
- 데스크톱의 짧은 메뉴 링크도 최소 44px 너비 확보
- 보이는 로고 문구를 접근 가능한 이름에 포함
- `src/data` 문서 예시를 `src/content`로 통일
- 최신 ESLint 10과 호환되지 않는 정적 접근성 플러그인을 강제 설치하지 않음. 접근성 회귀는 axe 브라우저 검사로 확인

## 아직 확인하지 않은 것

- 실제 모바일 Safari/Android 기기, Firefox, 화면 읽기 프로그램의 종합 검수
- 브라우저 자체 줌 200%의 수동 검수
- 아직 이관하지 않은 콘텐츠·이미지·PDF·메일 기능
- 최종 디자인 승인과 공개 승인

환경 제약과 미실행 항목을 통과로 바꾸지 않습니다. CI 결과와 화면 증거가 준비되면 이 기록을 갱신합니다.
